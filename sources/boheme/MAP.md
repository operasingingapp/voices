# Mapping La bohème (Ricordi vocal score, Carignani reduction, plate 99000, third Italian edition)

Score PDF: /home/claude/ext/boheme/src/vs.pdf (277 pages; PDF page N = printed page N, check the printed number).
Page images at 300 dpi: /home/claude/ext/boheme/pages/p-NNN.png (p-001.png = page 1); some may still be rendering:
if an image is missing, read the PDF page with the Read tool (pages: "N") instead. ZOOM (python PIL crop + resize)
whenever small print is unclear.

The opera is printed in four "quadri" (acts), each continuous, with rehearsal figures in parentheses (1), (2), ...
There are no numbered pieces. Your job is a faithful page-by-page map. For EVERY page in your range write:

## p. N
- quadro: I/II/III/IV (and if a new quadro or new scene heading starts on this page, quote the heading and
  the stage direction that follows, verbatim in Italian)
- figures: rehearsal figures printed on this page, e.g. (12) sys 2, (13) sys 4
- tempo/key/time: every tempo word, metronome mark, key signature change, time signature change, with system number
- sung: every singer entry on the page in order: printed singer name (as printed, e.g. "MAR.", "RODOLFO"), and
  the first words they sing at that entry (Italian, as printed). Group several lines of one singer. Include
  chorus entries (which chorus part: Soprani, Tenori, Bassi, Ragazzi, Venditori...) and offstage voices.
- stage: short English summary of printed stage directions (the italic/bracketed Italian), with the key Italian
  words quoted when they matter (entrances, exits, who speaks to whom)
- double bars / clear section ends: where and what follows (e.g. "double bar, sys 3; new tempo Andante")

Be exact: names and words as printed (accents, apostrophes). Do not guess from memory of the opera: write only
what this print shows. Note anything unusual (cuts marked, "Vi-de", alternative notes, ossia, spoken words,
"parlato", ad lib.).

Write your map to the file named in your task, nothing else. Reply with: the page range covered, where each
quadro starts/ends in your range, the full list of singers you saw, and anything odd.
