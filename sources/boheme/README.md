# La bohème: sources

- `vocal-score-ricordi-99000-IMSLP885132.pdf`: the score everything follows. Milan: G. Ricordi & C., 1897,
  plate 99000, piano reduction by Carlo Carignani, third Italian edition (Schickling 67.E.5, "nuova edizione con
  aggiunte dell'autore"). IMSLP #885132. Public domain (Puccini d. 1924, Carignani d. 1919, Illica d. 1919,
  Giacosa d. 1906). PDF page N = printed page N.
- Checking sources, used only to check our own text, never copied into the app:
  - Nico Castel's word-by-word IPA and literal translation (Leyerle). Still under copyright: NOT kept in this
    public repository; the user's copy is attached to the working conversation.
  - The libretto (Giacosa and Illica): to be added (original Ricordi libretto scan).
- `MAP.md`: how the score was mapped page by page; the maps go in `map/`.
