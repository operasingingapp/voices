# Instruments for the sung line

Oboe (with vibrato) and solo violin (arco, vibrato) from **VS Chamber Orchestra: Community Edition**
(VSCO 2 CE) by Versilian Studios, recorded by Sam Gossner and Simon Dalzell, released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain).
Source: <https://github.com/sgossner/VSCO-2-CE>.

Changed for this app: oboe `Vib` loud layer (v3; the files are named an octave low, so the true pitch is
used here), violin `Arco Vib` forte layer; each note levelled to the same loudness, cut to 6 s (oboe) or
7 s (violin) with a 0.5 s fade, re-encoded as 96 kbps MP3. `tuning.json` holds each recording's measured
pitch deviation in cents, which the player corrects. Files are named `<instrument>-<midi>.mp3`.
